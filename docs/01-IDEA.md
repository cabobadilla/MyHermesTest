# 01 — Idea

- **Proyecto:** MyHermesTest
- **Fecha:** 2026-10-07
- **Origen:** mensaje del usuario (Telegram)

## Requerimiento crudo

> "quiero que la pagina de demo de tipografias y colores sea como una landing
> page del mismo contenido de una empresa de consultoria agentica que al
> seleccionar en la barra superior o moverme a la derecha me permita vivir la
> experiencia de los colores y tipografias distintas y vivir el sitio en
> diferentes modos"

## Contexto adicional

- El repo `MyHermesTest` ya existe y ya contiene un `index.html`: una página
  estática que muestra "Hello World" en 10 combinaciones de paleta + tipografía,
  cada una en su propia sección, con soporte de modo claro/oscuro por
  `prefers-color-scheme` y un toggle manual Auto → Light → Dark.
- Publicada en GitHub Pages: https://cabobadilla.github.io/MyHermesTest/
- Este proyecto es además el **primer POC del harness HermesHarness**: se usa
  para validar el proceso, no solo el producto.

## Lo que explícitamente se pidió

- [ ] Que la página sea una **landing page** de una empresa de consultoría agéntica
- [ ] Que el **contenido sea el mismo** (el de la demo actual), no reemplazado
- [ ] Que se pueda **cambiar de estilo** desde una **barra superior**
- [ ] Que se pueda cambiar de estilo **moviéndose a la derecha**
- [ ] Que el visitante pueda **"vivir la experiencia"** de los distintos colores y tipografías
- [ ] Que se pueda **vivir el sitio en diferentes modos**
