Decisiones

  • Pieles token-driven — 13 tokens semánticos por piel; los componentes solo referencian var()
  • Transición horizontal — transform + opacity, comunica dirección
  • Contenido escrito una vez — la comparación entre pieles queda limpia
  • Tests sin dependencias — node --test, sin Playwright ni jsdom
  • Contrato de prompt + tests congelados — el Coder no toca los tests; se sellan con hash antes de despachar

  • Piel de marca por defecto
